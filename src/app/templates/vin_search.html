Поиск авто по VIN коду

OSINT

Введите 17-значный VIN код для получения полной информации об автомобиле. Система поддерживает проверку контрольной цифры, декодирование WMI/VDS/VIS, запрос к NHTSA vPIC API и генерацию OSINT ссылок для дальнейшего расследования.

Пример: 1C6RR7JM2FS578550 Формат: WMI (3) + VDS (5) + Check (1) + Year (1) + Plant (1) + Serial (6)
Что такое VIN?

Vehicle Identification Number — уникальный 17-значный код автомобиля. Содержит информацию о производителе, характеристиках, годе выпуска, заводе и серийном номере. Контрольная цифра (9-я позиция) защищает от подделки.

OSINT возможности

После декодирования система генерирует ссылки для проверки истории авто: Google, Copart, IAAI, Carfax, BidFax, NICB, EpicVIN и другие аукционы/базы. Можно также искать лица на фото автомобиля через EyeOfWeb.

Поддерживаемые проверки
  • Валидация формата (17 символов, без I,O,Q)
  • Проверка контрольной цифры (ISO 3779)
  • Декодирование WMI (производитель, страна)
  • Декодирование года выпуска (10-я позиция)
  • Завод-изготовитель (11-я позиция)
  • Серийный номер (12-17)
  • NHTSA vPIC API (140+ полей)
  • OSINT ссылки (12+ источников)
  • Интеграция с EyeOfWeb Image DB
